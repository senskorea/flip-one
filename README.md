# Flip One

Korean-first bilingual MVP for the Flip One startup platform.

The site is static and designed for GitHub Pages. It uses five focused routes:

- `index.html` introduces the Flip One story and pathways.
- `platform.html` contains the people directory and matching interface.
- `services.html` presents Ideation, Scaling, and Sustainability support.
- `resources.html` provides the searchable wiki-style knowledge base.
- `events.html` presents upcoming community events.

Korean is presented first, with an English language switch shared across every page.
